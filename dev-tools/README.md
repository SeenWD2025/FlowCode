## Available Tools

### update-root-mapfile.js

Aggregates all `mapfile.md` files into a single `root-mapfile.md` for project overview.

```bash
node dev-tools/update-root-mapfile.js
```

**When to run:**
- After adding new directories with mapfiles
- After significant mapfile updates
- Before project reviews or handoffs
