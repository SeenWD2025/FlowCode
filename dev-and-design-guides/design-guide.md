## Motion & Animation

### Principles
- Purposeful: Animations should communicate
- Quick: Keep durations short (150-300ms)
- Natural: Use easing functions

### Standard Durations
| Type | Duration | Easing |
|------|----------|--------|
| Micro | 150ms | ease-out |
| Small | 200ms | ease-out |
| Medium | 300ms | ease-in-out |
| Large | 400ms | ease-in-out |

## Accessibility Standards

### Requirements
- WCAG 2.1 AA compliance
- Minimum contrast ratios: 4.5:1 (text), 3:1 (large text)
- Keyboard navigation support
- Screen reader compatibility

### Testing Checklist
- [ ] Color contrast verified
- [ ] Focus states visible
- [ ] Alt text for images
- [ ] ARIA labels where needed
- [ ] Skip navigation link
- [ ] Form field labels
